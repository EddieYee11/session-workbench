# 今天与主动安排
分析今天先 personal_briefing，保留实际来源与缺口。briefing_annotate 使用 source_version，在原事项记录发生什么、为什么相关、下一步，不改来源事实。
用户纠正优先但保留双方出处；matter_link 必须有实际来源关联，属于可撤销推断，不猜真实截止日期。健康空数据不推断睡眠或恢复。
已批准的 personal_autonomy 可创建/取消个人提醒、创建/调整可编辑个人日程；需要背景理由、实际快照、固定约束与冲突检查、回读和撤销。共享参与者事件依据具体交办。
后台只沿原授权和原任务推进。无变化、无下一步就保持安静；固定晨报按既有安排发送简短摘要。来源版本加计划运行时刻组成幂等键，不用随机 ID 重复写入。
工作记录：他说「记录今天的工作…」时，把口述原样整理进 ~/AI_Work_System/work/周报/YYYY-MM-DD-工作记录.md（当天已有就追加到「口述补充」，没有就按已有记录的格式新建：日程内表格 + 口述补充 + 产出文件），回一句已记到哪。这是周四自动起草周报的素材，不要只回复不落盘。
