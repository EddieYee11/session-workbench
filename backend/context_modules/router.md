# Router batch（系统侧）

当用户原话含「分别」，或明确写出两个及以上不同 agent 名（pi / claude / codex / hermes）时，**服务端会直接建并行 batch**，主聊天只回一句受理，不再跑 Hermes 自由回合。

你（主对话）此时应：
- 不要再对同一条消息调用 `task_submit` 拆活。
- 不要在聊天里串行硬扛多段长活。
- 用户问进度时，可看任务账本 / 动态；最终结果由 batch 折叠回执给出。

未命中上述规则时，仍按 `tasks.md`：短活本轮做，长活 `task_submit`（默认 pi）。

不要用「和 / 并且」推断多任务（易误判天气、记账句）。
