# 会话工作台 UI 改版与产品建议（2026-09-30）

分支：`ui-polish-kimi`。方向：保持浅色单主题，视觉质感向 Kimi / ChatGPT / cue 一类精致 AI 应用靠拢，动效全面丝滑化。

## 一、本次 UI 改版内容

### 设计系统（新增 `Theme.kt`）

- **色彩**：暖纸面 `#F7F7F5` + 纯白卡片 + 靛蓝强调色 `#3D5BF0`（替代原「纯黑当主色」方案）；Pi 会话保留绿色识别，Codex 改用强调蓝；审批卡、用户气泡、工具输出、分隔线均有专属语义色。
- **动效规范 `Motion`**：统一弹簧曲线（Emphasized / Gentle / Settle / Bouncy）与补间（Fade / Tint），全 App 动效节奏一致。
- **通用动效组件**：
  - `rememberPress` —— 按压缩小回弹，已挂到发送键、圆形图标键、顶栏 Pill；
  - `RowAppear` —— 新消息淡入 + 轻微上浮（仅最新一条播放，历史消息滚动回屏不重复播放）；
  - `StatusDot` —— 呼吸状态点，用于运行中会话与工具执行；
  - `ThinkingDots` —— 三点起伏打字指示器，替代原静态黑点「正在处理」。

### 界面落地

- 会话列表：选中态改为浅蓝底，「等待回应」用强调色提示，运行中会话显示呼吸点；
- 侧栏导航：选中项浅蓝底 + 蓝字；底部头像改用强调色；
- 输入框：发丝描边 + 加深浮起阴影，发送键黑色 → 靛蓝并带按压回弹与颜色过渡，光标改强调色；
- 消息流：用户气泡加大圆角，工具输出卡片加描边，执行中工具显示呼吸点，过程组箭头改为旋转动画；
- 顶栏 Pill、回到底部按钮等全部接入描边与按压反馈。

验证：`./gradlew assembleDebug` 通过（JDK 21）。

## 二、产品经理视角：功能优化与新增建议

按「影响 × 成本」排序，P0 为建议下个迭代优先做。

### P0 · 高频痛点

1. **审批推送直达操作**：目前「需要你回应」靠应用内展示；通知（StatusWorker 已轮询）应带「允许 / 拒绝」操作按钮，不用进 App 即可处理，是移动端最大效率点。
2. **代码块一键复制**：助手回复用 Markwon 渲染，代码块无法单独复制；加长按代码块复制或块级复制按钮，编程场景刚需。
3. **会话未读徽标**：侧栏会话行对「已完成未查看 / 等待回应」显示计数或色点，配合现有「工作中」筛选形成完整收件箱心智。
4. **发送失败重试**：断网 / busy 时发送失败目前依赖错误弹窗；草稿保留（已有）+ 消息级「重试」按钮。

### P1 · 体验增强

1. **常用 Prompt 模板**：把高频开场白（如「继续昨天的事」「跑一遍测试」）做成输入框上方快捷 chips，可自定义。
2. **完成摘要推送**：任务结束时推送一条「干了什么」的一句话摘要（取最后一条助手消息首部），决定是否点进来看。
3. **会话导出 Markdown**：会话详情菜单加「导出为 Markdown」，便于把结果沉淀进工作区文档。
4. **平板 / 折叠屏双栏优化**：已有 600dp 宽屏断点和侧栏，补充会话内「对话 + 终端」真正并排，而非切换。
5. **桌面小组件**：显示「N 个会话等待回应」+ 一键继续上次会话，绕开启动路径。

### P2 · 长期价值

 1. **用量统计页**：按 Agent / 目录统计会话数、运行时长，帮助判断自动化投入产出。
 2. **语音输入原生按钮**：目前依赖键盘麦克风，输入框内嵌语音键降低发现成本。
 3. **终端按键自定义**：常用键（Ctrl、Tab）顺序与增删做成可配置。
 4. **多服务器支持**：`Store.base` 单地址，未来如有第二台机器，做服务器切换器。

### 不建议做

- 深色主题：用户已明确「只精修现有浅色」，设计系统预留了色板集中定义，未来真要加时成本低；
- 账号体系 / 云同步：与「个人工具 + Mac mini 自建服务」定位冲突。
