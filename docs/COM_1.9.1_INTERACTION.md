# Com! 1.9.1：跟手滑动与折叠操作记录

2026-10-04。Android 1.9.1 / versionCode 22；沿用后端 1.9.0 / API 契约 2，本轮没有修改或重启生产后端。

## 本轮变化

- 主对话上滑时收起输入法；在最新消息底部继续下拉时聚焦原输入框并弹出输入法，保持最新消息和原草稿。历史中的下拉、惯性滚动和程序定位不会唤起输入法。工作会话共用键盘手势。
- 左上搜索、中央形象／状态条和右上更多随手指距离整体向上移出或向下移回。没有按“是否阅读历史”突然淡出；中途松手保持当前露出距离。顶部裁剪在消息视窗内。
- 主对话搜索只有左上入口。删除输入区上方整行文字按钮；回到最新为输入框旁 40dp 圆形向下箭头（不覆盖正文、不增加整行），点击回到底部并恢复顶栏。
- 主对话工作过程卡、总结卡与全部步骤详情默认折叠，包括失败步骤；工作会话的处理过程和工具日志也需点按查看，搜索命中仅标“含匹配”，不自动展开。
- 形象状态来自当前实际阶段与工具名：分析用户请求、分析工具结果、正在使用 Bash／Read／Edit 等、正在撰写回复。保留其他真实工具名，不推测没有上报的工具、模型或内部推理。
