# Com! 「Her 式」私人助理升级（2026-11-10）

参考：Eddie 发的截图（微信里一个叫「Her」的 AI 助理）。截图里的三段对话：

1. 助理整理打车信息：目的地、路程「约 7 公里，18 分钟」、价格「惊喜特价 ¥10 · 快车 ¥16 · 专车 ¥27」，每项一行，标签加粗。
   接着**给明确建议并说理由**：「我建议叫**快车 ¥16**。特价要等拼单匹配，可能多等一会儿，你赶着上班就别省这几块了。」
   再**主动指出数据新旧**：「你手机定位是昨晚 21:45 更新的，显示在酒店。你现在还在酒店吧？」
   最后**一句话确认**：「没问题回我一句「叫」就发单。」外加一句带人情味的收尾：「最后一天了，出差辛苦 😄」
2. Eddie 回「好 叫吧」→ 助理执行并回执：「叫到了，司机大概 **2 分钟**到，下楼吧：」+ 车 / 司机 / 上车点三条。
3. 隔了一段时间，聊天流中间出现居中的时间分隔「9:46 AM」，助理**自己发来**一条：「德亚希腊酸奶在派送了，今天注意收一下。」后面附原始物流文字。

## 现状（已有，不重写）

- `backend/proactive.py`：只有定时晨报 09:00 / 晚间复盘 21:00，经 `background_events` 进主对话。
- `backend/triggers.py` / `evals.py` / `event_rules.json` / `decisions.py`：事件层 observe，只落库，不进聊天。
- `backend/reply_style.py`、`backend/hermes_prompt.py`：回复风格与系统提示（Hermes profile com-personal）。
- `backend/reply_options.py`：末行 `[[选项: A | B]]` 渲染成快捷回复。
- iOS `ios/Com/Views/ChatView.swift` / `ChatCollectionView.swift`：主聊天，无时间分隔。
- 规则：**最终点击由 Eddie**（邮件发送、付款提交、内容发布这三类，只准备好不执行）；其他交办直达。

## 差距 → 三条并行线

### 线 A：事件触发的「顺口提醒」（后端）
截图第 3 段。现在 7 天内主对话几乎没有非定时的主动消息。
- 新模块 `backend/nudges.py`：从事件层（matters / triggers 已归并的事项）挑出「今天跟他有关、需要他注意的一件事」，生成**一条短消息**写进主对话，与普通助理消息同一种气泡。
- 首批类型：快递派送/待取件（顺丰/京东/菜鸟等关键词，来源可以是微信服务号、短信、邮件已采到的事项）、1 小时内的日程、出行（航班/火车）变动。规则写进 `event_rules.json` 风格的数据表，可改文件生效。
- 文案模板：第一句是人话结论（「德亚希腊酸奶在派送了，今天注意收一下。」），需要时第二段附原始关键信息（单号/快递员），不超过 80 字结论。
- 约束：同一事项只提醒一次（内容指纹 + 状态变化才再提）；遵守 proactive 已有的 quiet_start/quiet_end 与 paused、intensity；每天上限（balanced=6 条）；推送走现有 push_notifications（Bark）。
- 不做任何外发动作，只是提醒。

### 线 B：一句话确认执行 + 数据新旧提示 + 语气（后端）
截图第 1、2 段。
- 新模块 `backend/pending_actions.py`：助理提出一个**待确认动作**时登记（动作描述、确认词如「叫」「记」「订」、过期时间默认 30 分钟、绑定的执行参数/任务描述）。Eddie 下一条消息是短肯定（「好」「叫吧」「可以」「行」「发吧」「就这个」或命中确认词）→ 直接执行该动作并回执；否定（「算了」「不用」）→ 取消；其他话 → 保留待定，不误触发。
- 执行仍走现有任务通道（create_task / 现有工具）；属于「最终点击由 Eddie」三类的动作，确认后也只做到准备完毕停在按钮前，并在回执里说清楚。
- 数据新旧：给主对话上下文注入「关键数据的更新时间」（定位/设备节点、日历同步、记账、健康），超过阈值（定位 > 2 小时、日历 > 6 小时）时在提示里标注「较旧」，让模型像截图那样顺口确认一句。数据源以 `device_nodes.py` / `personal_hub.py` 现有字段为准，没有就跳过，不编。
- 语气（只改 `hermes_prompt.py` / `reply_style.py` 的文案）：有多个选项时**给一个明确建议 + 一句贴他处境的理由**；事实信息用「**标签**：值」短列表；要他确认动作时末尾写「回我一句「X」就……」并同时给 `[[选项: X | 再想想]]`；场合合适（出差、熬夜、周末）可以加一句轻的人情话，不要每条都加，不用客服腔。

### 线 C：iOS 聊天观感（iOS）
- 时间分隔：相邻两条消息间隔 ≥ 10 分钟时，在中间插居中的浅灰小字时间（今天「9:46」，昨天「昨天 21:45」，更早「11月8日 09:00」），样式参考微信。
- 主动消息与普通助理消息用同一气泡，不加卡片框；可在气泡外不加标签（像截图一样自然）。
- 待确认动作：助理消息带确认选项时，快捷回复的第一个胶囊（确认词）用 accent 实色，其余描边。
- 加 UI 测试截图验收（`--ui-testing` 下构造三段截图式对话的假数据）。
