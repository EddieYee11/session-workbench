## 一句话

整个 App 按方向 C 重做：**三个 tab（Com / 在办 / 工作）**、**顶栏住着手绘伙伴**、**它主动发的便签和对话排在同一条流里**，状态全部翻成印章词表。功能层把「今天」页、待批准、任务、信源状态合并成一个「待处理」模型，流、在办、顶栏角色、Dock 徽标都从它取数。

## 2. 视觉系统（`Views/DesignSystem.swift`）

- Token 名沿用：background #F3EEE3 / surface #FFFCF6 / fill #ECE5D6 / separator 墨 14% 虚线 / textPrimary #2A2620 / accent 朱砂 #B9533A / ink；深色各有一套。
- 字阶：宋体（Noto Serif SC，OFL，已裁成 GB2312 子集各 2.3 MB，`Resources/Fonts/`）只给 20 标题、16「它的判断」、13 区块标签、12 印章；正文 15、元信息 13 苹方。
- 便签：6pt 圆角 + 长投影 + ±0.4° 倾斜；焦点便签贴朱砂纸胶带；草稿写在横线纸上；状态=印章（等待批准 / 执行中 / 已送达 / 结果未知 / 已完成，外加真实的 待验收 / 等你回应 / 失败）。
- 纸底：18pt 点阵（Canvas），不用位图。

## 3. 角色（`Views/Character.swift`）

- Claude Design 的 SVG 线稿逐条移植：自带一个 SVG path 解析器（M/L/H/V/Q/C/Z，相对坐标），线稿字符串原样保留，Canvas 绘制。
- 8 个状态：空闲（打盹 Zz）、读取（捧信踱步）、思考（铅笔 + 三点）、执行（盖章）、派活（纸飞机）、等我批准（举「等你点头」）、交付（递卡）、信源断了（举「邮箱断了」抖动）。
- 状态由真实事件驱动（`FlowCards.swift` `stripState`）：SSE 舞台状态 > 待批准数 > 信源断了 > 空闲；减少动态效果 / 低电量 / 后台时静止。
- 角色在左时字在右；要你点头、派活、出错、交付时走到右边，字换到左边。

## 4. 功能升级（不只是换皮）

1. **待处理模型**（`PendingItem`）：合并 agency 事项卡、派活待批准、等你回应 / 待验收 / 结果未知的任务。流、在办、顶栏数字、Dock 红点、待处理清单共用。
2. **三种便签形态**：自动型（一句判断 + 主按钮，派活批准用朱砂）、表态型（摘要 + 横线纸草稿 + 交给 Com）、复杂型（去看 / 看进展）。同来源 ≥2 张自动叠成一沓。
3. **划掉**：左划或「晚点」= `later` 24 小时；菜单里仍有已处理 / 不再关注。任务和待批准不能划掉。
4. **信源断了**：连接器状态是 needs_connection / unavailable 且没被手动关闭 → 流里系统便签 + 顶栏举牌 + 工作台信箱格打叉；按钮直达重新授权页。
5. **账本便签**：本月已花 + 最大分类，点开原支出明细。
6. **刷新策略**：流里的便签数据每 60 秒补一次（不随 SSE），切 tab 只拉本 tab；聊天仍 SSE 优先。
7. **任务详情**：印章头部 → 要你决定（验收勾选）→ 步骤（做完划线勾掉、当前实心、等你朱砂框）→ 成果与证据。
8. **派新活**从工作页右上和项目详情都能进；项目详情列出可继续的会话。
