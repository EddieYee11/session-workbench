# Com! 1.3.2

修复 Pi 快捷小窗重复打开后需要再次点麦克风的问题。每次新呼出时都发起一次录音请求；活动窗口再次收到系统助手入口时也会启动，已有录音中则继续当前录音。恢复旧发送任务不再挡住新录音，之前的任务仍由 WorkManager 在后台送达。旧的未发送草稿保留到新录音有效结束；上一条仍在发送时，其录音文件留给后台任务使用。

首次使用需要系统麦克风权限；无权限或麦克风被占用时，窗口显示对应提示。0.5 秒静音发送与小窗内显示回复沿用 [1.3.1 的实现](com-1.3.1.md)。

验证：Android assembleDebug 与 testDebugUnitTest 通过；1.3.2 已覆盖安装到小米折叠屏。系统麦克风记录显示快捷小窗启动后自动开启过录音。第二次重开时的实体操作验收待完成。
