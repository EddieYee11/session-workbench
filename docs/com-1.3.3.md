# Com! 1.3.3 · 原生交互与触感

在 `ui-overhaul-20261001`（`1aa9050`）上改进键盘、小窗手势和日常反馈，保留 Pi 圆脸、Codex 毛绒伙伴、背靠背切换与悬浮阴影。

## 行为变化

- 首页随键盘和可用空间收拢，优先保留输入与角色切换；取消首页、历史列表的逐项延迟入场。
- 输入框保持无投影；普通按钮轻按压，页面与卡片使用平面中性表面。
- 小窗随手指改变尺寸和圆角，支持反向拖动、取消、回弹中重新抓取；按松手速度和位置决定展开或返回。
- 手指停住再松开不复用旧甩动速度；折叠或旋转导致的窗口重建保留当前录音。
- 角色移动等待目标布局完成，连续导航可从当前位置重新转向；保留同一个角色与输入表面。
- 切换角色、发送、录音启停、展开及审批操作使用系统语义触感，尊重系统触感设置，不新增振动权限。重复重组、回复文字增长、麦克风音量变化不触发震动。
- Markdown 回复仅在正文变化时重新解析，避免拖动、键盘和音量更新时重复排版。
- 保留每次小窗自动录音、检测有效语音后的 0.5 秒静默发送、小窗内回复以及继续完整会话的既有规则。

## 构建

```sh
cd android
./gradlew testDebugUnitTest assembleBenchmark
```

`benchmark` 使用 Release 的 R8 与资源优化，关闭调试，沿用本机调试签名以覆盖已装测试版本并保留数据；不包含发布商店的签名材料。版本号 `1.3.3`，版本代码 `7`。

产物：`android/app/build/outputs/apk/benchmark/app-benchmark.apk`。

## 验证边界

`testDebugUnitTest` 的 17 项测试通过，覆盖静默发送判定、会话回复范围、小窗松手方向/速度与拖后停住的判断。`assembleBenchmark` 构建及其发布关键 Lint 检查通过。

本轮 ADB 未检测到设备，尚未安装此版；没有把构建通过计为真机布局、触感或帧率验收。

真机需要检查：内外屏键盘开合无裁切、连续角色切换、上下拖动小窗和中途反向、真实录音的启停震动与静默发送、系统关闭触感后无震动。实测帧耗时与主观触感不能由构建成功代替。
