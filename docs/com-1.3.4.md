# Com! 1.3.4 · 模型与推理选择

主页和会话输入框左侧的「＋」打开原生底部面板。模型按提供方分组并可搜索；选择模型后显示该模型的推理水平。新会话的高级设置使用同一个面板。选择保存在手机上，下一条消息才应用到对应会话。

模型目录从 Mac mini 实时获取。Codex 使用 app-server 的 `model/list`，发送回合时通过 `turn/start` 应用模型和推理水平。Pi 使用本机 `pi --list-models`，在已托管会话空闲时由扩展切换模型；扩展确认成功后才发送用户正文。相同配置的后续消息不重复切换。

已有会话一旦指定模型，不能假装通过空值恢复 Mac 默认；需要新建会话。Pi 的空推理选项表示沿用当前强度。Pi 模型目录只给出是否支持推理，不给出逐模型的精确强度；如果所选档位被 Pi 降级，后端拒绝切换并保留消息。

验证：Android `testDebugUnitTest assembleBenchmark` 通过，后端 15 项测试通过；Mac mini 实际接口返回 41 个 Pi 模型、7 个 Codex 模型，Codex 推理档位按真实 `reasoningEffort` 字段读出。`1.3.4`（versionCode 8）已覆盖安装在小米折叠屏，原有应用数据保留。未发送新的测试消息到用户会话。
