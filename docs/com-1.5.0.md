# Com! 1.5.0

2026-10-02，包名 `work.eddie.sessions`，versionCode 11。沿用 mini 的 dot 任务闭环实现并做本次产品优化。

## 使用路径

- **对话**：Hermes 持久主聊天。明确交办可创建多个独立任务；闲聊继续留在主聊天；后续限制关联到原任务。
- **今天**：Com2 样式的七日日历、当天事件，以及既有账本、待处理与在途工作。日历数据通过手机 CalendarContract.Instances 直接读取；循环、全天、跨日事件按本地日期处理。只申请读取权限，事件不会上传到 mini。点击事件可打开系统日历详情。
- **任务**：mini 持久任务账本，显示真实执行状态、约束和送达回执、结果与原执行会话。执行结束显示待验收。长执行指令默认收在「执行详情」内；离线缓存明确标记并禁用控制。
- **工作**：保留手动 Pi / Codex 会话、终端与历史。
- **更多**：日历、账本、连接和系统能力设置。

底栏使用 Com2 的白色浮动胶囊、灰色线性图标和深色选中项。手机与展开屏均在底部；键盘出现时收起。图标直接取已安装 Coms! 的实际自适应与传统图标资源，保留 Com! 名称和原包名以便升级。

## 电源键快速语音

默认系统助手入口 `ACTION_ASSIST` 进入独立 `QuickVoiceActivity`。它以透明底部小窗覆盖当前应用，立即录音，讲话后的停顿自动结束录音；沿用 mini 语音转写和 Hermes 主对话接口，收到持久接收回执后收起，不打开 Com! 主界面，也不等待助理回答。识别或发送失败可以在原小窗重试，取消录音不发送。请求使用 `quickvoice-<capture>` 幂等 ID。

小窗沿用 Com! 既有 `QuickVoiceSheet` 的圆角面板、把手、身份胶囊、流体圆脸 `CompanionAvatar`、录音波形、宽胶囊按钮与入退场动效。动画组件和本地资源直接复用；状态接到倾听、识别/发送、收到回执。按此次要求移除原先的展开跳转。

原记账小窗改为独立 `ExpenseVoiceActivity`，从「语音记账」快捷方式和原系统能力入口访问。电源键入口直接发送自然语音，不再把每句话当成账单。手机系统助手需要指向 Com!；小米已有的电源长按助手分发保留，双击支付与电源菜单设置沿用原值。

通过合成中文音频核对 mini 转写接口返回 200，4 秒音频识别耗时 0.885 秒；有一个同音字误识别。真正的说话音量、环境噪声和停顿习惯仍需手持试用。

显式启用的 `QuickVoiceWindowTest` 检查 Settings 前台唤起底部小窗、真实转写发送、成功收窗恢复原任务，整个过程没有 `MainActivity` 跳转。手机默认助手角色、组件、麦克风与日历权限已配置；先前助手值备份于本机 Downloads。

旧动画布局融合后的实测同样通过 1 项 live 检查。实机已亲自查看圆脸倾听动画、小窗波形与底部按钮，取消后恢复原来的 X 前台页面。长按电源的系统分发与默认助手已读回确认；实际手持电源按压和真实用户讲话仍保留实体操作验收。

## 执行与授权

任务保存来源消息、完成条件、目录、授权、task ID、native session/turn ID。独立后台循环支持两项只读任务同时执行，同目录写任务串行；未知执行状态不自动重放。主聊天先返回受理，随后真实执行器结果回流，二者分别显示。

自动任务支持明确交办的 Codex 只读检查和项目内修改。完整权限 Pi 与额外操作保留工作建议。Codex 补充和停止针对原 native turn；送达与执行完成分别记录。现有 Pi tmux 会话尚未接 RPC steer；自动验收、未知执行恢复也未实现。
