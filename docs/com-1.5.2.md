# Com! 1.5.2 · 消息发送与键盘联动

Android 包名沿用 `work.eddie.sessions`，版本号 1.5.2 / versionCode 13。最终设备包使用现有安装证书，启用 R8 和资源压缩，原位安装保留配对与本地历史。

## 本次变化

- 主窗口明确启用 edge-to-edge，保留 `adjustResize`。根容器统一消费系统栏和 IME Insets；弹层由自己的窗口处理。输入框和消息视口跟随系统键盘进度，底栏同步收缩和淡出，标题固定。阅读底部时保持最新消息可见，阅读历史时保留消息位置。
- 一套本地发送状态覆盖工作页发送按钮、输入法 SEND、首页创建、高级创建与 Hermes 转写后提交。提交前保存实际文字布局和屏幕坐标；弹层与主窗口用相同屏幕坐标。
- 短文本在 250ms 内从输入文字变为消息文字，同时插值位置、字号、颜色、背景尺寸和圆角；曲线为 `(0.1991947291, 0.01064453125, 0.2792093704, 0.91025390625)`。实际 LazyColumn 的整行高度和间距使用同一进度，已有消息平滑让位。回执、时间和任务元数据落位后再显示。
- 超过十行、Markdown、代码、图片、排版发生换行变化或输入区域无法完整显示的文字采用淡入、位移和轻微缩放。远端消息与加载历史不会触发本地 Morph。系统关闭动画或应用退到后台时释放动画状态。
- 右滑回复，左滑在当前对话引用；达到阈值一次轻触反馈，图标放大，释放后弹回。引用预览可取消，仍需添加说明并手动发送。
- 引用在后端追加迁移后持久保存；`/health.features.message_references_v1` 用于阻止旧服务忽略引用。原始被引用消息由服务核对，引用文字不能自动变成新授权。
- 原生 Pi/Codex 的真实回显绑定请求号；相同正文与客户端时间不会用来猜测消息身份。持久受理回执对应“已发送”，实际运行事件对应“正在处理”，不显示无证据的 READ。
- 明确未提交的拒收可保留草稿并释放该次待确认请求；网络故障和提交后不确定状态继续使用原请求号核实，避免重复交办。

输入法通过 `ImeAction.Send` 请求发送键；保留输入框的多行编辑和光标处手动换行。豆包输入法最终显示的键盘按钮仍由输入法决定。

此前螃蟹状态动画、渐变标题、分色气泡、Hermes 表情和授权卡、小窗 Pi 的实现继续保留，见 [1.5.1](com-1.5.1.md)。
