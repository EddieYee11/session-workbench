# Com! 的 Markdown / Hindsight 分工、同步与召回边界

来源为工作区权威文档 `docs/MARKDOWN_HINDSIGHT_MEMORY.md`（及 `README.md` 的边界描述）。以下内容只依据来源资料归纳，未包含任何凭据。

## 一、分工：Markdown 是权威，Hindsight 是可重建索引

| 层 | 角色 |
|---|---|
| **Markdown** | 唯一权威档案（权威原文） |
| **Hindsight 0.10.2** | 可重建的语义索引，不是权威来源 |

- Hindsight **不摄入** Git、会话或整个工作区。
- **没有**会自动 retain 聊天的官方 Coding Agent 扩展。
- **没有**提供模型可直接写入 Hindsight 的 retain 工具，也**不会**自动把每轮对话存进去。
- 用户要求“记下”时，流程是：**Agent 先写合适的工作区 Markdown → 再由同步器摄入**。

## 二、同步

**范围（显式白名单，非自动扫描全部工作区）**

- `personal-main`：`_global/本体画像/` 的现役 Markdown；`_global/记忆库/知识/` 与 `事件/`。
- `project-com`：Com! README 与 `docs/` 的 Markdown。
- **排除**：归档、同步冲突副本、符号链接、大于 512 KiB 的文件、`memory-reflections/` 提炼草稿。
- 扩展其他项目时需修改 `backend/memory.py` 的显式 `ROUTES`，不扫描所有隐私资料与配置目录。

**同步机制**

- `work.eddie.com-memory-sync` 服务：每轮完成后等待 **60 秒**检查变化；首次导入较慢，**逐文件**完成并保存清单，失败会重试。
- 每个文件使用**稳定 `document_id`**；文件修改时**删除旧索引后重建**，文件删除时**也删除索引**。
- 运行数据**不通过 Syncthing 同步**（数据库与中文向量/排序模型缓存均为本机独立存放）。

**重建边界**

- 重建仅删除**专属 bank 的索引和清单**，然后重新同步；**不得删除权威 Markdown**。
- 可停掉索引与召回服务（bootout 两个新 LaunchAgent）而不影响原 Markdown 与 Com 的普通聊天。

## 三、召回边界

- **准入条件**：召回只接受**带来源路径与 SHA256、且对应当前原文件版本**的事实。
- **不注入**：索引过期、文件被删除、或未经 Markdown 同步的事实。
- **排除**：自动衍生的 observation **不参与召回**（以避免丢失来源与版本）。
- **触发点**：每个 Pi operational turn 在 `before_agent_start` 自动召回个人与 Com bank，作为 `com-memory` 历史上下文注入；Pi 也可调用**只读** `memory_recall`。
- **效力边界**：记忆**不授予新操作权限**，也**不保证实时状态正确**；动态事实应回读权威原文并现场核验。
- **失败语义**：服务超时最多约 **8 秒**且不中断聊天；未查询成功时返回 `unavailable` / `partial`，**不声称没有历史记忆**。

## 四、哪些是设计约束

来源资料中以“原则性/禁止性”措辞表述、属于**设计约束**的条目：

1. **Markdown 唯一权威、Hindsight 仅为可重建索引** —— 定位约束。
2. **不摄入 Git、会话或整个工作区** —— 摄入范围约束。
3. **无 retain 工具、不自动存每轮对话** —— 写入路径约束（只能走 Markdown→同步器）。
4. **同步为显式白名单 / 显式 ROUTES，不扫描全部工作区与隐私配置目录** —— 范围约束。
5. **固定排除项**：归档、同步冲突副本、符号链接、>512 KiB 文件、`memory-reflections/` 草稿 —— 摄入排除约束。
6. **召回只接受带来源路径+SHA256 且对应当前版本的事实；过期/已删/未同步不注入；observation 不参与召回** —— 召回准入约束。
7. **重建只删专属 bank 索引与清单，不得删除权威 Markdown** —— 数据安全约束。
8. **记忆不授予权限、不保证实时状态，动态事实需回读核验** —— 效力约束。
9. **超时上限约 8 秒、失败返回 `unavailable`/`partial` 而不谎称无历史** —— 失败语义约束。
10. **reflect 草稿标记为模型推断、默认不重新摄入；不得当作已确认档案** —— 自我强化防护约束。

> 说明：以上“设计约束”是依据来源文档的表述归纳（如“唯一”“不摄入”“不得”“只接受”等措辞），并非额外添加的外部结论。凭据类信息（如连接令牌）来源仅说明其不入库，此处不展开任何具体值。
